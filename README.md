# Rien de grave

Récit interactif web (three.js) de Hadrien Basch : Claire, factrice à Valberne (ville fictive), de la victoire du RN en 2027 à 2035. Chaque scène porte des tampons sourcés (« Déjà arrivé », « Au programme du RN », « Déjà proposé », « Pas encore arrivé »).

- Jeu : `rien-de-grave.html` (un seul fichier, ouvrir via un serveur local, ex. `python3 -m http.server`)
- Assets : `props/` et `glb/` (`.glb.wasm` = GLB renommé pour l'hébergeur d'artefacts), `tex/`, `sons/`
- Paquet itch : `python3 tools/build_itch.py <dossier_build>` (voir COMPTE-RENDU.md)
- Variantes en pause : `la-rue.html`, `la-rue-fp.html`
- Passation complète : **COMPTE-RENDU.md**

Modèles et textures : Poly Haven (CC0). Moteur : three.js (MIT).
